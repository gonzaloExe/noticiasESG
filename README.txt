noticiasESG
================
Portal de noticias realizado en PHP puro.

REQUISITOS
- PHP 7.4 o superior
- Apache/Nginx
- No requiere MySQL

INSTALACIÓN
1. Descomprimir noticiasESG.zip.
2. Subir la carpeta al servidor web.
3. Abrir /noticiasESG/ en el navegador.

ESTRUCTURA
- index.php       Portada con las 6 noticias.
- noticia.php     Página individual de cada noticia.
- data/noticias.php  Contenido editable de las noticias.
- assets/css/     Diseño.
- assets/js/      JavaScript.

NOTA
Las noticias incluidas fueron redactadas a partir de información publicada por la Escuela Superior de Guerra/UNDEF y Argentina.gob.ar. Las imágenes de demostración se cargan desde Unsplash.
